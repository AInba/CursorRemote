# 开发计划

[English](../product-plan.md)

目标是让 CursorRemote 更容易装上，也更放心在离开电脑后继续用。顺序按使用者会先碰到的问题排列。做完一项，就同时改这份中文和英文计划。

## 这一轮已做

- 飞书限制编辑时，保留上一条消息，状态行写明代理没有停。被限流的编辑不会再补发一条重复消息。
- 网页先说明通知权限，点「允许」后浏览器才询问。之后才提供加到主屏幕。提醒仍然要求页面开着；普通的局域网 HTTP 地址两者都不会出现。
- Telegram 里，不是当前打开的标签会标明「不是正在监视的标签」，打开那个标签后才继续更新。其他已打开窗口的当前标签仍在后台刷新。不会去点隐藏标签，否则会改掉 Cursor 里正在看的对话。
- Setup 面板在选择局域网（`0.0.0.0`）且网页密码为空时警告：同一网络上的任何人都能控制 Cursor。
- 网页在提取变旧时提示把 Cursor 切回前台。空代码块说明要等 Cursor 画出编辑器行；一直空着时也提示把 Cursor 切到前台。
- Setup 面板给每个已绑定的飞书或 QQ 账号一个移除按钮。中继在跑时立刻生效。中继没在跑时，删掉本机记录，下次启动后生效。允许名单里的账号下次启动会回来，面板会说明这一点。
- QQ 的问卷选项和计划操作与审批一样，挂在被动回复窗口里，也可以用 `/do`。
- 飞书 `/history` 回看当前窗口里更早的对话（默认 30 条，最多 80 条）。平时的推送仍然只带最近一段。
- 飞书和 QQ 私聊可以用 `/windows`、`/tabs`、`/model`（或序号、名称）列出并切换 Cursor 窗口、对话标签和模型。之后的消息发到选中的窗口。
- 入门演练增加可选的飞书和 QQ 步骤。填上对应的 App ID 后，该步记为完成。
- Setup 面板跟随编辑器语言。中文编辑器使用中文标签，飞书、QQ 和安装说明链到 `docs/zh/`。
- Setup 面板会探测 Cursor 调试端口（CDP 地址上的 `/json`）。端口没开时，网络页和一条警告会说明：完全退出 Cursor，再用 `--remote-debugging-port=9222` 启动。
- 飞书和 QQ 页显示长连接或网关是否真的连上，包括缺密钥、QQ `4914`、IP 白名单被拒。只保存凭证不再显示成已经连好。
- 发送结果和卡片执行结果带上 Cursor 窗口名（`已发送到：项目名`）。
- `/status` 用中文状态（空闲、等待审批等），并列出待审批。
- 飞书和 QQ 私聊支持 `/unbind`。写在 `FEISHU_ALLOWED_USERS` 或 `QQ_ALLOWED_USERS` 里的账号，进程下次启动会重新加入。
- 在飞书群里 `/bind` 不会注册，也不会用掉口令。
- QQ 的 `/status` 在有审批时给出 `/do <id>`。若 4 分钟被动窗口已过，这个用户再发一条消息后，按钮可以挂到那条消息上。
- 飞书超长文本会注明已截断。
- Setup 面板：飞书写明先启动再保存长连接；QQ 写明沙箱和 `4914`；绑定码每秒倒计时；复制后有反馈。启用任一机器人时说明聊天内容会离开本机。
