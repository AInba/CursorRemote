# 发布前冒烟检查

[English](../smoke-checklist.md)

自动化测试通过之后、发布之前，手工过一遍这些项。

## 环境

- [ ] 在干净的机器或配置文件上安装打包好的 VSIX（不要用开发检出目录）
- [ ] 确认服务启动并打印 `=== CursorRemote vX.Y.Z ===`，版本号正确

## 网页

- [ ] 浏览器能打开网页，控制台没有 `io`、`vendor-socket.io.min.js` 的错误
- [ ] 站点图标能加载（没有 404）
- [ ] 登录 / 会话能保持（刷新后仍在登录态）
- [ ] Cursor 处于活动状态时，连接点显示 Connected
- [ ] 代理活动时状态有闪烁文案，结束后回到 Idle
- [ ] 消息类型渲染正确（human、assistant、tool、thought）
- [ ] 运行命令卡片显示命令文本，以及 Skip / Run 按钮
- [ ] 审批之后，审批按钮消失，并出现工具结果
- [ ] 计划卡片显示标题、进度，View Plan 打开包含完整计划的弹层
- [ ] 计划模型选择器打开，并列出模型选项
- [ ] 代码块保留换行，diff 有红 / 绿着色
- [ ] 向上滚动后停止自动滚到底；新消息不会把视口拽回去

## Telegram

- [ ] 实时活动有闪烁（spoiler），例如带 spoiler 的 `● Thinking…`
- [ ] 活动结束后闪烁消失（消息被删除）
- [ ] 思考步骤摘要在进行中带 spoiler，完成后去掉
- [ ] 活动行与对应的步骤摘要不重复
- [ ] 运行命令显示命令文本，以及 Skip / Run 内联按钮
- [ ] 计划块渲染待办，以及 View Plan / Build 按钮

## 飞书

- [ ] 保存凭证并重启中继后，Setup 面板出现 6 位 `/bind` 口令
- [ ] 私聊发送 `/bind <口令>` 只接受一次；同一口令再发会被拒绝
- [ ] 该私聊里的普通文本能进入当前 Cursor 输入框
- [ ] 审批卡片上的按钮能执行或跳过对应的 Cursor 操作
- [ ] 只在群里发送 `/bind` 不会往 Cursor 里打字

## QQ

- [ ] 打开沙箱后，网关能到达 ready（不会一直停在 `4914`）
- [ ] 从扫码聊天打开的私聊里，`/bind` 只接受一次
- [ ] 普通文本能进入当前 Cursor 输入框
- [ ] 这条消息发出后的几分钟内，审批键盘（或 `/do <id>`）能执行操作
- [ ] 会话不会被完整代理对话刷屏；`/status` 返回一份快照

## 边界情况

- [ ] 在多个 Cursor 窗口之间切换时，每个窗口的状态正确
- [ ] 把 Cursor 放到后台（macOS）会降级而不是崩溃，状态显示为过期
- [ ] 快速切换标签不会产生重复消息
