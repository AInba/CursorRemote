## Feishu (optional)

A private Feishu chat can control the active Cursor window. The relay dials Feishu, so this machine does not need a public webhook.

### What you'll do
1. Create a self-built app and enable the bot
2. Paste the App ID and App Secret on the **Feishu** tab of the Setup Panel
3. Restart, wait until that tab says the long connection is ready, then save **使用长连接接收事件** in the Feishu console
4. Scan the bind code and send `/bind` in a **private** chat

Chat content goes through Feishu. Chinese steps: `docs/zh/feishu_setup.md`.
